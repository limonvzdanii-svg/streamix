# STREAMIX 2.0

Платформа интернет-телевидения: просмотр прямых эфиров и возможность создавать собственные каналы.

## Сейчас

Первый интерфейсный прототип:
- адаптивная главная страница;
- переключение светлой и тёмной темы;
- окна регистрации и входа (пока без серверной авторизации);
- блок каталога каналов и описание возможностей платформы.

## Принятая логика аккаунтов и каналов

1. Пользователь регистрируется и может пользоваться платформой без создания канала.
2. Создание канала — добровольное действие после регистрации.
3. После создания канала ему выдаётся отдельный постоянный ключ трансляции.
4. Ключ хранится на серверной стороне, а не в cookie браузера.
5. Владелец может просмотреть ключ и сбросить его.
6. При сбросе старый ключ немедленно отзывается, новый ключ выдаётся для этого канала.
7. У каждого канала свой ключ.

## Технологический план

- Cloudflare Workers — API и серверная логика.
- Cloudflare D1 — пользователи, каналы, хеши ключей и метаданные.
- Отдельный RTMP ingest-сервис — приём видеопотока из OBS. Cloudflare Workers сами по себе RTMP-сервером не являются.

## Запуск локально

Откройте `index.html` в браузере. Для текущего прототипа сборка не нужна.

**Важно:** регистрация, вход, создание каналов и трансляции пока не работают — это следующий этап. Не вводите настоящие пароли в прототип.
